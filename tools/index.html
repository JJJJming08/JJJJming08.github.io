工具箱

这里放我的在线小工具集合。目前收录两个自己写的工具。

🔐 随机密码生成器

支持 8–18 位、特殊符号、防逆向推演，还能从网页 / 文本读取字符需求自动生成。

如果内嵌页面加载不出来，可以 在新标签页打开密码生成器。

🔣 编解码工具

一站式编解码：Base64 / Base32 / Hex / URL / Unicode / ROT13 / Morse / 二进制 / GZip / JSON，支持「一键智能识别解码」自动判断编码类型。

纯本地运行，数据不离开浏览器，粘贴密文、Flag、Token 都能直接解。

如果内嵌页面加载不出来，可以 在新标签页打开编解码工具。

后续会把更多顺手的小工具陆续放进这个工具箱。
