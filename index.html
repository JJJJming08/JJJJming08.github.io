编解码工具上线：一键识别，密文秒解

博客 工具箱 里又添了一个新工具：编解码工具。

https://code-decoder-tftrf289wjt.qoder.zone/

为什么做

调接口、抓包、翻别人网页的时候，经常会遇到一堆看不懂的东西：一串 eyJhbGciOi...、一段 %E4%BD%A0%E5%A5%BD、一坨看着像乱码的 48656c6c6f。它们其实是 Base64、URL 编码、十六进制，只是换了层皮。

市面上的在线解码站点大多有两个问题：要把内容上传到别人的服务器（涉密的 Token、Cookie、内部数据贴上去就等于交出去了），以及得自己猜编码类型——试 Base64 不行再试 URL，猜错了就白折腾。

所以自己写了一个放在博客里，核心就两点：纯本地跑，不联网；不用猜，一键自动识别。

它做到了什么

支持 11 种编解码方式，双向可用：

方式 典型长相 常见场景
Base64 eyJhbGciOiJIUzI1NiJ9 JWT、接口返回、图片内嵌
Base32 MFRGGZDFMZTWQ2LK 二维码、邮件验证码
Hex 48656c6c6f 抓包、二进制文件头
URL %E4%BD%A0%E5%A5%BD 中文转义、链接参数
Unicode \u4f60\u597d JSON 里的中文
ROT13 Uryyb 简单字母替换
Morse -... -.-- .-. --- ..- 老式电码
二进制 01001000 01101001 计算机基础
GZip 乱码开头 压缩数据
HTML &amp; &lt; 网页实体
JSON {"key": "value"} 格式化/压缩

几个用起来比较爽的点：

  • 一键智能识别：不指定方式，它会把所有解码方式都试一遍，按结果可读性排序，靠谱的那条直接标「可读性高」。省掉逐个试的过程。
  • 双向：不是只能解，也能编。改个参数、造个测试数据都用得上。
  • 支持大文件：「打开文件…」能直接读本地文件，不用先复制粘贴。
  • 结果可留档：导出全部结果为 TXT；导出 JSON 会带上方式名称、时间、输入、输出，适合排查问题时留证据。
  • 纯本地运行，数据不离开浏览器 —— 这是我最在意的一点。

怎么用

  1. 进 工具箱 在页面内直接用，粘贴内容点「一键智能识别解码」；
  2. 或直接打开：https://code-decoder-tftrf289wjt.qoder.zone/

三个按钮顺手用一下：从剪贴板粘贴（省得手动找）、清空（别留敏感数据在页面上）、清除结果。

顺带提醒：即使工具本身不联网，粘贴进去的内容仍然会留在浏览器内存里。用完记得点「清空」。

一点碎碎念

做这个工具的时候，最花时间的不是各个编解码算法本身——那些都是标准实现，写起来很顺——而是**「智能识别」的排序逻辑**。

因为 Base64 和 Base32 的字符集高度重叠，一段短字符串经常能同时被两种方式「成功」解出，但只有一个是对的。所以不能只看「解出来了没有」，还得看解出来的内容像不像人话：可打印字符比例、中文占比、有没有奇怪的替换字符（�），综合打个分再排序。

这大概是「能跑」和「好用」之间差距最明显的一个地方。

工具箱慢慢在填了。目前两个：密码生成器、编解码工具。后面遇到什么顺手的小需求就继续往里塞。

随机密码生成器上线 & 我的工具箱

最近自己动手做了一个随机密码生成器，已经放进了博客的 工具箱。

为什么做

市面上的密码管理器要么太重、要么要注册账号。我想要一个：打开就能用、能记住历史、长度可调，最关键是尽量复杂、防止被逆向推演的小工具。于是自己写一个。

它做到了什么

能力 说明
长度 8–18 位 滑块调节，默认 12
特殊符号 常见符号 + 可开启的扩展符号（数学 / 希腊字母 / 货币等 100+ 字符）
防逆向推演 拒绝连续字符、键盘序列、常见弱密码词；强制大小写混合；带实时强度条
读取网页需求 粘贴文本或一个 URL，从内容里提取字符再生成
记住密码 浏览器本地保存最近 10 条，刷新不丢

怎么用

  • 进 工具箱 在页面内直接使用；
  • 或直接打开：https://pwd-generator-30021.app.workbuddy.host/

密码这种东西，能自己掌控生成规则总归更安心。后面有空再往工具箱里塞点别的小玩意。
